# Pipeline de Dados Automatizado — Indicadores Financeiros (BCB)

> Projeto em construção.

Pipeline automatizado em Python que coleta indicadores do Banco Central do Brasil
(Dólar, Selic, IPCA) via API SGS, valida os dados e os armazena em PostgreSQL,
com execução diária orquestrada via GitHub Actions.

## Stack
- Python
- PostgreSQL
- Docker / Docker Compose
- GitHub Actions
